# QuantPilot

AI-powered stock strategy backtesting SaaS: describe a trading strategy in plain
English, get it parsed into a validated strategy definition, backtested on historical
data, and explained.

For development tasks, use the installed agent-engineering skill matching the requested
outcome. Use `deliver-change` for full implementation; use the relevant phase skill
for narrower requests. Read the [project workflow guide](docs/agent-engineering.md) for
routing and applicable standards during planning, implementation, verification, and
review. Explicit task limits and project authorities govern. Report a missing skill;
do not treat this reference as permission to install or publish.
